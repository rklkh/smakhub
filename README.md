# SmakHub 03

Нова робоча версія, створена ВИКЛЮЧНО з SmakHub 2. Попередні роботи не змінювалися.
Команда: Калюх Р. Д. (КА-41), Худікова М. В. (КА-44), Корецька М. В. (КА-45).

Почніть зі START-HERE.md: стек, детальний план до захисту ЛР3 та кроки підключення сервісів.

## Зроблено
- Пошук восьми карток каталогу за назвою та всіма вказаними інгредієнтами.
- Комбіновані фільтри, параметри URL, скидання та порожній результат.
- Підготовлена інтеграція Supabase Auth: реєстрація, вхід, account.html і вихід.
- Початкова SQL-схема profiles, recipes, favorites, contact_messages із RLS.
- Збірка dist/ з виключенням SQL, документації, тестів та службових файлів.

## Ще не підключено
Віддалений Supabase: js/config.js містить порожні публічні параметри.
SQL ще не виконано у віддаленій БД; Auth, доставка email і серверні правила
не перевірялися на реальному проєкті. Контактна форма не надсилає повідомлень.
Каталог поки читає локальну розмітку; картки ще ведуть на спільний приклад борщу з ЛР2.

## Запуск
Відкрити index.html через локальний HTTP-сервер. Для хостингу:

    node scripts/build.cjs

Завантажити dist/ у статичний хостинг. Для Supabase потрібні Project URL і Publishable key.
Секретні ключі, пароль БД та SMTP-пароль НЕ додаються до клієнтського JavaScript.

## Перевірка
Chrome: 40 перевірок макетів, пошук/фільтри, URL, порожні результати, відсутність
хибної реєстрації без конфігурації. Результат: checks/results.json.
Це не перевірка віддаленої БД. Firefox, Safari та Edge цієї версії не перевірені.
