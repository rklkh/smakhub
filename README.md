# SmakHub

SmakHub — сайт рецептів із пошуком за назвою та інгредієнтами. Лабораторна робота № 3 присвячена CSS-оформленню й адаптації сторінок сайту.

Бригада № 4 — Калюх Р. Д. (КА-41), Худікова М. В. (КА-44), Корецька М. В. (КА-45).

[Відкрити сайт](https://smakhub.kaliukhromanpc.workers.dev/)

## Виконання лабораторної роботи № 3

| Вимога | Реалізація |
| --- | --- |
| Базове оформлення | Сторінки використовують спільну палітру й типографіку з брендбуку. Зовнішні стилі оформлюють заголовки, абзаци, посилання, списки, таблиці та форми. |
| Адаптивний дизайн | Медіазапити змінюють кількість колонок, розміри блоків і навігацію. На вузькому екрані меню відкривається кнопкою. |
| Форми та валідація | Поля й кнопки мають спільні стилі. Базові обмеження задано через `required`, `type="email"` і `minlength`. Стани помилки оформлено через `:user-invalid` та `[aria-invalid="true"]`. |
| Grid і Flexbox | Grid формує сітку карток і колонки сторінки рецепта. Flexbox вирівнює елементи навігації й групи кнопок. |
| Кросбраузерність | Протокол перевірки Chrome, Firefox, Edge і Safari та скриншоти для різних екранів оформлюються у звіті. |
| Організація CSS | `css/style.css` підключає через `@import` базові стилі (`base.css`), макети (`layout.css`), компоненти (`components.css`), адаптивні правила (`responsive.css`) і стилі окремих розділів. Використано звичайний CSS. |
| Робота з Git | HTML, CSS та інші вихідні файли доступні в цьому репозиторії. |
