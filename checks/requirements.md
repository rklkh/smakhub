# SmakHub: матриця вимог перед розробкою 0.5

Джерела: звіт бригади «ЛР №1 бригада №4.pdf» (розділи 1–9), звіт «ЛР2_бригада4.pdf», чотири оригінальні методички з папки web і вихідний код SmakHub 04. Його наявність у цій таблиці не засвідчує проходження перевірки.
