# Перевірки SmakHub 0.5

## Виконано локально

- Chrome 157.0.8103.79, Firefox 144.0.2, Playwright WebKit 26.0.
  У кожному по 33 комбінації сторінок і розмірів. Перевірено
  ширину, структуру HTML, завантаження модулів CSS і відкривання мобільного меню.
  WebKit перевірено окремо від застосунку Safari. Edge і Safari як застосунки
  ще потребують перевірки.
- У локальному PostgreSQL (PGlite) виконано міграції 001–003d. Перевірено
  початкові рецепти, пошук, подання рецепта з фото, відсутність чернеток у
  гостя, відмову автору в самосхваленні, публікацію модератором, оцінку,
  коментар, історію й відмову в записі заблокованому користувачу.
- В ізольованій базі 20 009 рецептів і 500 одночасно поставлених у чергу
  пошуків із двома фільтрами. Всі запити повернули очікувану кількість
  рядків. Час для p95 — 62,98 с, для всієї черги — 66,05 с. Це
  однопроцесний PostgreSQL WASM без мережі. Вимогу про 2 секунди при
  500 одночасних користувачах цей запуск не підтвердив.

- W3C Nu HTML Checker перевірив 14 вихідних HTML-файлів версії 0.5 без
  помилок. JSON-відповіді є в `checks/w3c/`.
- Chrome підтвердив перемикання UA/EN без перезавантаження, вхід до редактора
  з обмеженням для гостей і завантаження форми планувальника.

## Залишилося перевірити перед здачею

- Відправлення та відкриття справжнього листа відновлення пароля після
  налаштування домену й SMTP у чинному Supabase.
- Повний користувацький сценарій на Cloudflare після міграції.
- Перевірка в застосунках Safari й Microsoft Edge.
- Мережевий тест завантаження сторінок за ≤3 с і пошуку за ≤2 с, навантаження
  на контрольованому стенді з 500 клієнтами та вимірювання 99% за місяць.
